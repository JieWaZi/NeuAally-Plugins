# GitHub 插件

通过应用私有的官方 CLI 2.102.0 设备授权共享账号，使用官方远程 MCP 处理仓库、Issue 和 Pull Request。登录不要求填写应用 ID。

二维码与网页入口均打开官方原始设备确认页面，输入应用显示的一次性验证码后确认。组织 SSO 或仓库限制仍遵循 GitHub 的授权策略。

CLI 程序固定版本与摘要，MCP 由 GitHub 托管持续更新。插件清单与共享认证适配由 NeuxAlly contributors 编写，操作能力由官方 MCP 提供。官方 CLI 的 MIT 许可见 LICENSE.github-cli，完整来源见 provenance.json。
