# 飞书办公

[English](README.md) | [简体中文](README.zh-CN.md)

让伙伴协助处理飞书文档、多维表格、日程和任务，从整理内容到跟进协作事项。

## 可以做什么

- 起草和整理文档，查找相关内容，将零散笔记组织为清晰的报告。
- 查询和更新表格记录，整理项目信息并汇总进展。
- 查看日程，明确时间与参与人，安排协作活动。
- 创建和跟进任务，整理负责人、截止时间和完成情况。
- 结合会议记录、项目资料与待办事项，形成可执行的工作计划。

## 开始使用

在插件库中为伙伴安装飞书办公，选择连接并按提示完成授权。根据要处理的工作选择合适的账号和访问权限。

在对话中提供相关文档或表格链接，说明希望得到的结果。安排日程或任务时，请补充参与人、日期、时区和截止时间。需要先审阅内容时，可以请伙伴先准备草稿，再执行修改。

## 试着这样说

- “把这些会议笔记整理成飞书文档，列出决策和行动项。”
- “汇总这张项目表的进展，标出已经逾期的工作。”
- “查找下周适合召开项目评审的时间。”
- “根据这份文档整理后续任务，建议负责人和截止时间。”
- “阅读这份文档，准备一份简明的进展说明。”

伙伴会在你授予的访问范围内处理工作。你可以在插件设置中管理连接。
