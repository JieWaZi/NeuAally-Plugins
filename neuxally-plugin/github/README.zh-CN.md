# GitHub

[English](README.md) | [简体中文](README.zh-CN.md)

检索 GitHub 仓库代码、跟进议题和拉取请求，协助代码审查与变更分析。

## 主要能力

- 搜索仓库和代码，查找具体实现、示例与相关项目。
- 阅读议题和拉取请求，整理其中的讨论、决策与尚未解决的问题。
- 检查变更文件和补丁，解释影响并准备评审建议。
- 查看变更相关的构建和测试结果。
- 汇总仓库动态与已合并的拉取请求。

## 权限前提

可访问的内容取决于已连接 GitHub 账号及其获授权限。私有仓库需要相应仓库的访问权限，组织策略可能要求额外批准。账号凭据应保存在受保护的账号配置中。

## 实用场景

- **代码调查：** 查找某项功能的实现位置，追溯相关变更。
- **议题梳理：** 整理问题背景、关联拉取请求与待解决事项。
- **变更评审：** 检查补丁正确性、潜在风险和遗漏的测试。
- **进展跟踪：** 根据已合并工作、待处理议题和检查结果汇总进展。
