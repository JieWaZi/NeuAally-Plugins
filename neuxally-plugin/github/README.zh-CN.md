# GitHub

[English](README.md) | [简体中文](README.zh-CN.md)

让伙伴检索仓库代码、跟进议题和拉取请求，协助评审变更与团队协作。

## 可以做什么

- 搜索仓库和代码，查找示例、具体实现与相关项目。
- 阅读议题和拉取请求，整理讨论结论与待跟进事项。
- 检查变更文件，解释补丁并准备代码评审建议。
- 排查变更相关的构建和测试结果。
- 汇总仓库动态，整理简明的工作进展。

## 开始使用

在插件库中为伙伴安装 GitHub，按插件设置要求配置访问权限，使用能够访问所需内容的账号。然后打开对话，提供仓库、议题或拉取请求链接，并说明希望完成的工作。

访问私有仓库时，请使用具有相应权限的账号。账号凭据请保存在连接设置中。

## 试着这样说

- “找到这个仓库处理登录的代码，解释主要流程。”
- “总结这个议题的讨论，列出尚未解决的问题。”
- “评审这个拉取请求，重点检查正确性和遗漏的测试。”
- “解释这个拉取请求的检查为什么失败。”
- “根据本周已合并的拉取请求整理一份进展周报。”

提供仓库名称、相关链接，以及工作范围或评审重点，可以帮助伙伴更准确地处理任务。
