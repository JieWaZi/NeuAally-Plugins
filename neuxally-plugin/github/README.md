# GitHub

[English](README.md) | [简体中文](README.zh-CN.md)

Search repository code, follow issues and pull requests, and review changes on GitHub.

## Capabilities

- Search repositories and code to locate implementations, examples and related projects.
- Read issues and pull requests, summarize their discussions and identify unresolved questions.
- Inspect changed files and patches, explain their impact and prepare review suggestions.
- Check build and test results associated with a change.
- Summarize repository activity and merged pull requests.

## Access requirements

Access depends on the connected GitHub account and the permissions granted to it. Private repositories require access to the relevant repository; organization policies may require additional approval. Credentials should be kept in protected account configuration.

## Practical uses

- **Code investigation:** locate the code responsible for a feature and trace the relevant changes.
- **Issue triage:** summarize an issue's history, related pull requests and open questions.
- **Pull request review:** examine a patch for correctness, risks and missing test coverage.
- **Change tracking:** organize merged work, outstanding issues and check results into a progress report.
