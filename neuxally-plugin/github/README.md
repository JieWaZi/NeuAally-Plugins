# GitHub

[English](README.md) | [简体中文](README.zh-CN.md)

Find repository code, follow issues and pull requests, and review changes with your partner.

## What you can do

- Search repositories and code to find examples, implementations and related projects.
- Read issues and pull requests, summarize discussions and identify follow-up work.
- Review changed files, explain a patch and prepare review suggestions.
- Check build and test results while investigating a change.
- Organize repository activity into a concise progress update.

## Get started

Install GitHub for a partner in the plugin library. Configure access as requested in the plugin settings, using an account that can access the content you need. Then open a conversation and share a repository, issue or pull request link, along with what you want to achieve.

For private repositories, use an account with access to the requested content. Keep account credentials in the connection settings.

## Try asking

- “Find where this repository handles sign-in and explain the main flow.”
- “Summarize the discussion on this issue and list the unresolved questions.”
- “Review this pull request for correctness and missing test coverage.”
- “Explain why the checks on this pull request failed.”
- “Prepare a weekly update from the merged pull requests in this repository.”

Include the repository name, relevant links and any scope or review priorities so the partner can focus on the right work.
